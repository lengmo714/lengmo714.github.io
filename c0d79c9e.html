iOS 接入 Firebase FCM 推送完整教程：APNs .p8 Key 配置

分类于 Cocos Creator
介绍 iOS 应用接入 Firebase Cloud Messaging（FCM）推送的完整配置流程，包括 Push Notifications、APNs .p8 Key 创建以及 Firebase 后台上传配置。

接入 FCM 前的准备

1、Apple Developer账号，这个是必须的，不然测试都无法测试
2、App ID开启Push Notification

Firebase 添加 iOS 应用

1、先去firbase控制台创建一个iOS应用，这里创建和安卓不一样，需要先去苹果后台创建一个应用，填写应用ID
2、然后去下图所示位置，上传相应APNs密钥（官方推荐）

当然也可以上传APNs证书，也就是我们平时说的.p12证书。上面密钥是.p8为后缀的文件。

创建 APNs Authentication Key（.p8）

进入Apple Developer后台创建APNs Key
如下图所示

这里两个随便填，因为我们是接推送，所以这里勾选Apple Push Notifications service(APNs)

然后继续，这里点save然后将密钥Download下来即可。


注意这里黄色文本的提示，这个密钥只能下载一次，所以一定要妥善保管

然后再去Firebase后台去填写相关信息就可以了啦
