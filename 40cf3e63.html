Xcode Undefined symbol swiftCompatibility51 / 56 / Concurrency 解决方法

分类于 Cocos Creator
解决 Xcode 编译 iOS 项目出现 Undefined symbol swiftCompatibility51、swiftCompatibility56、swiftCompatibilityConcurrency，以及 library swiftCompatibility51 not found 等错误。

在 iOS 工程接入 AdMob 等包含 Swift 编译产物的 SDK 后，Xcode 链接阶段可能出现 swiftCompatibility51、swiftCompatibility56 或 swiftCompatibilityConcurrency 的 Undefined symbol 错误。这通常表示最终链接时没有正确找到 Swift Compatibility Libraries。
